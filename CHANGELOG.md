# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2025-11-25

### Added
- Initial release of aaPanel MCP Server
- Docker management (start, stop, restart, status)
- PM2 management (start, stop, restart, logs, status)
- SSL certificate management (list, status, renew)
- Database management (create, list, Drupal setup)
- System monitoring (resources, info, dashboard)
- Service management (unified control)
- Comprehensive documentation
- Installation scripts
- Example configurations
- Troubleshooting guide

### Features
- 20+ MCP methods for server management
- Support for multiple configuration methods (config file, environment variables)
- Automatic password generation for databases
- Complete Drupal database setup automation
- Cross-platform support (Linux, macOS)
- Secure configuration handling

### Documentation
- Complete README with installation instructions
- API reference documentation
- Usage examples
- Troubleshooting guide
- Distribution guide
